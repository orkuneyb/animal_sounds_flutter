# 1.6.0 (versionCode 14) — Play Console release notes

New: every animal redrawn in 3D, 153 animals in all, sounds for more than
100 of them, a new icon, and a fix for the compare screen in Arabic. Each
block is under 500 characters. Play Console uses `<ar>` for Arabic.

<en-US>
What's new in 1.6.0
• 153 animals to discover — more than 100 of them new
• Every animal has a brand-new 3D picture
• Sounds for over 100 animals; the others say "sound coming soon"
• New facts for every new animal, read aloud in 8 languages
• New app icon
• Fixed: the compare screen now shows its bars in Arabic
</en-US>
