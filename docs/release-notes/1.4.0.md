# 1.4.0 (versionCode 12) — Play Console release notes

New: one-time "Remove ads" purchase for parents (product `remove_ads`),
bundled Nunito font (no network fetch), quiz early-exit fix, non-fatal
error reporting. Each block is under 500 characters. Play Console uses
`<ar>` for Arabic.
